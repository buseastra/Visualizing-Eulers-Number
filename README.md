# Visualizing Euler's Number ✨📐

*Approaching $e \approx 2.71828$, one step closer to infinity.*  
Terminal-based Python visualization of Euler's number ($e$)  
*Euler sayısının ($e$) Python ile terminal tabanlı görselleştirmesi.*

---

### 🚀 How to Run / Nasıl Çalıştırılır?

1. Download `euler_harmonics.py` (or copy the code). / `euler_harmonics.py` dosyasını indirin (veya kodu kopyalayın).
2. Open a terminal that supports ANSI colors (VS Code, Windows Terminal, macOS Terminal, or Termux). / Renkli çıktıyı (ANSI) destekleyen bir terminal açın.
3. Run the script in the file's directory / Dosyanın bulunduğu klasörde şu komutu çalıştırın:

```bash
python eulers_number.py
```
